# Tasks - 02 SQL in Postgres for analytics

## Delivery format
- notebook или `.sql` + notebook с проверками
- ориентир: 150-220 строк SQL и Python-обвязки

## Task A - Exploratory SQL
- исследовать структуру минимум трех таблиц
- построить базовые counts, суммы и средние значения
- зафиксировать первичные ключи и потенциальные join keys

## Task B - Analytical marts
- построить витрину продаж по дням и категориям
- построить вторую витрину по городам, пользователям или каналам
- использовать `cte`, чтобы разложить логику на понятные этапы
- документировать логику вычисления ключевых метрик

## Task C - Window analytics and validation
- построить ranking внутри категории или города
- добавить rolling metric или накопительную сумму
- проверить витрины на дубли, null и аномальные суммы
- подготовить короткий review: какие SQL-конструкции оказались самыми полезными

## Expected result
- есть минимум две осмысленные витрины
- есть хотя бы один use case с window function
- есть SQL-checks качества результата

## Questions for review
- почему витрина и ad hoc query - это не одно и то же?
- как понять, что `join` размножил строки?
- почему хороший SQL должен быть читаемым, а не только корректным?
